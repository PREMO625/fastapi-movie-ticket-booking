**FastAPI Internship – Final Project Allocation & Submission**

After completing **6 days of FastAPI training**, you must build a **complete real-world FastAPI backend project** using the concepts learned during the internship.

This project evaluates your ability to design APIs, structure backend systems, and implement real application workflows.

# **Project Objective**

Build a **fully functional FastAPI backend system** implementing:

* GET APIs  
* POST APIs with Pydantic validation  
* Helper functions  
* CRUD operations  
* Multi-step workflows  
* Search, Sorting, and Pagination

Your project must include **all Day 1 – Day 6 concepts**.

# **Concepts That Must Be Implemented**

## **1  GET APIs**

* Home route  
* List all records  
* Get record by ID  
* Summary/count endpoint

## **2  POST \+ Pydantic**

* Request body validation  
* Field constraints  
* Error handling

## **3 Helper Functions**

Examples:

find\_item()  
calculate\_total()  
filter\_logic()

Use `Query()` parameters and `is not None` conditions.

## **Day 4  CRUD Operations**

Implement:

* POST → create record  
* PUT → update record  
* DELETE → remove record

Handle:

201 Created  
404 Not Found

## **Day 5  Multi-Step Workflow**

Create **3 or more connected endpoints**.

Examples:

| Cart → Order → DeliveryBorrow → Return → HistoryBooking → Check-in → Check-out |
| :---- |

## **Day 6  Advanced APIs**

Implement:

* Keyword search  
* Sorting results  
* Pagination  
* Combined browsing endpoint
